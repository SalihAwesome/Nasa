# Jezero comparison evidence

The comparison view retains the original MEDA card and its missing scored fields.
It also reads `app/public/data/mars/jezero-comparison.json`, generated by
`pipeline/fetch_comparison.py`. This file contains separately named measurements
and a documented unit clarification. No supplemental number enters scoring.

Run from `pipeline/` after installing its dev dependency group:

```powershell
./.venv/Scripts/python.exe fetch_comparison.py
./.venv/Scripts/python.exe -m pytest tests/test_fetch_comparison.py -q
```

Raw downloads are cached in ignored `data/raw/comparison/`; remove an individual
cached file to fetch it again. The generated JSON records each source URL and SHA-256.
The RDS CSV must match the PDS label's MD5 and declared record count. A changed
paper context, unit or archive schema fails the pipeline instead of guessing.

| Displayed quantity | Source and reduction | Limits |
| --- | --- | --- |
| Relative humidity | Official MEDA bundle documentation states local relative humidity in %RH. The measured value remains the U07 sol 300 ten-minute-bin mean. Martínez et al. (2023), section 2, identifies ice as the saturation reference. | XML itself has no unit. Earth uses a separate 2 m RH product. A common saturation reference has not been established, so the table explains why a direct difference is not calculated. |
| TES orbital albedo, 14.7% | Martínez et al. (2023), section 4 / figure 14, reports a collocated TES retrieval of 0.147. The pipeline extracts that passage from the fetched paper and converts the fraction to percent. | Regional retrieval, about 300 km², 0.25–2.9 µm, around 14:00 LTST. This is a published orbital product, not MEDA sol 300 reflectivity. |
| MEDA recorded UV detector flux, 2.79 W/m² | Calibrated RDS TOP 3, sol 300. Average recorded samples in each ten-minute LMST bin, then select the highest recorded bin mean. | 250–400 nm, ±15° field of view. 29,656 valid observations occupy 54 bins. The peak bin starts at 11:00 LMST. Missing bins remain missing. This is neither an Earth UV index nor hemispherical daily exposure. |

Source and coverage details can be expanded inside each affected table cell. A
direct difference is shown only for paired primary values with the same stated
unit and saturation reference (where relevant). Supplemental products retain their own names, and their difference cell
explains why no direct subtraction is shown. Percentage-point differences are
rounded to two decimal places to avoid exposing binary floating-point noise.
